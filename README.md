# Penguin's Last Stand

A small game created with Godot 4.7. You are a penguin and must last as long as possible against waves of enemies.

AI disclaimer: Used for helping debug errors, refactoring logic, and planning feature implementation. Models used: Opus 4.8, Opus 5
